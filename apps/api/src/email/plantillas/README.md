# Plantillas de mail

Una función pura por mail (`(datos) => { asunto, html, texto }`), con sus textos en
`../mensajes/<idioma>.json` (D84). La de código de ingreso la agrega la spec 007
(`codigo-ingreso.ts`) y la de avisos la 012 (`aviso.ts`); "Contanos qué te parece", la 013.
Colores de un único `COLORES_EMAIL` que nombra el token de `docs/17` de cada valor.
